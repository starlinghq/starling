Modifications made by StarlingHq (Apache-2.0, section 4(b)):

  - The Qwen3Model backbone (token embedding, 28 decoder layers, final norm) is exported as one graph that runs the
    whole input once, without a KV cache and without a position_ids input (positions 0 to sequence - 1). The causal
    attention mask is built in the graph from the 2-D attention mask as an additive float32 mask (key k is visible to
    query q when k <= q and the key is not padding). Output: last_hidden_state (1024).
  - The weights were converted from bfloat16 to float32 and exported to ONNX (opset 20) with the PyTorch dynamo
    exporter (torch 2.14.1, transformers 5.18.0, onnx 1.23.1, onnxscript 0.7.2). The language model head is not
    included.
  - Exporter metadata and doc strings were removed so the files are reproducible; the weights are stored in the
    external data file model.onnx.data.
  - Last-token pooling, L2 normalization, the instruction prompts and Matryoshka truncation are not part of the graph.
  - tokenizer.json, tokenizer_config.json, config.json and config_sentence_transformers.json are the original files at
    the revision above, unchanged.

Reproduction: model-pipeline/reference/qwen3-embedding/export_qwen3_onnx.py --model embedding followed by
release_qwen3_onnx.py --model embedding in https://github.com/starlinghq/starling (pinned environment
requirements.txt). The expected sizes and SHA-256 digests are in build-lock.json and SHA256SUMS.
