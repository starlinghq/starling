Modifications made by StarlingHq (Apache-2.0, section 4(b)):

  - The Qwen3Model backbone (token embedding, 28 decoder layers, final norm) is exported as one graph that runs the
    whole input once, without a KV cache and without a position_ids input (positions 0 to sequence - 1). The causal
    attention mask is built in the graph from the 2-D attention mask as an additive float32 mask (key k is visible to
    query q when k <= q and the key is not padding).
  - The language model head is reduced to two rows of the tied embedding matrix, in the order [no = token 2152,
    yes = token 9693], copied into a 2 x 1024 matrix. Outputs: yes_no_logits (2 per position) and last_hidden_state
    (1024). Logits over the full 151,669-token vocabulary are not available, so the graph cannot generate text.
  - The weights were converted from bfloat16 to float32 and exported to ONNX (opset 20) with the PyTorch dynamo
    exporter (torch 2.14.1, transformers 5.18.0, onnx 1.23.1, onnxscript 0.7.2).
  - Exporter metadata and doc strings were removed so the files are reproducible; the weights are stored in the
    external data file model.onnx.data.
  - The prompt format (system prefix, instruction, query and document, assistant suffix), truncation, the score
    (yes - no at the last valid position) and its sigmoid are not part of the graph.
  - tokenizer.json, tokenizer_config.json, config.json, chat_template.jinja and 1_LogitScore/config.json are the
    original files at the revision above, unchanged.
