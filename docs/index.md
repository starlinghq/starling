# Starling

.NET implementations of AI models with reproducible evidence. This site is built by docfx from the repository: nothing on it is written for the site alone.

- **[API reference](api/index.md):** the public API of every package under `ai-dotnet/src/`, from the XML documentation comments the packages ship.
- **[Model catalog](catalog/README.md)** and **[compatibility matrix](catalog/compatibility-matrix.md):** every registered profile, its maturity, gates, capabilities and platforms. Generated by `model-pipeline catalog` from the registry manifests; `catalog/catalog.json` is the machine-readable form.
- **[Evidence index](evidence/README.md):** every evidence directory under `docs/evidence/`, with its date and the profiles and gates it supports. Generated by `model-pipeline evidence-index`.
- **[Support policy](support-policy.md):** what each maturity label commits the project to, and the public API deprecation window.

Maturity belongs to profiles, not packages: a package page in the API reference does not say whether a profile is Stable. The catalog does.

Links from the catalog and evidence pages to other repository files (manifests, evidence records, plans) are relative links in the repository; follow them on GitHub.

Build it locally from the repository root (writes `artifacts/docfx/_site`, ignored by Git):

```sh
dotnet tool restore
dotnet docfx docs/docfx.json
```
