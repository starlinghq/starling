# EmbeddingGemma 2 video embeddings: implementation evidence

Contract of 2026-10-11 (Mark; `model-pipeline/admissions/embeddinggemma-2.md`, Decision update, video): video-only and interleaved text/image/video embeddings at the checkpoint's settings (1 fps, at most 32 frames, 140 soft tokens per frame, no timestamps), Experimental; upstream quirks kept for parity (one frame under 2 s, index-based sampling, FFmpeg's default 10-bit conversion); decoded frames in the model package; frames without timing rejected by default with upstream's behaviour as an explicit option; an optional FFmpeg.AutoGen adapter on the user's own LGPL FFmpeg 8.x, shipping no FFmpeg binaries. Binding tolerances: `model-pipeline/protected/embeddinggemma-2/video-fp32-{cpu,cuda}/tolerances.yaml`; accepted fixtures: `video-fp32-cpu/` (PR #47). Spike: `docs/m0/embeddinggemma2-video-spike.md`.

One workstation: Intel i7-5820K (12 threads, AVX2), 94 GB RAM, Linux x64, .NET 10, ONNX Runtime 1.30.0; FFmpeg `n8.1.3-17-gc389840894` (BtbN LGPL shared build, `fetch_eg2_ffmpeg.sh`, SHA-256 checked); CUDA on GPU 1 only (RTX 4060 Ti, `CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1`, CUDA 13 and cuDNN 9 from the nvidia wheels; GPU 0 belongs to another workload and was not used). Fixture videos regenerated byte for byte by `make_eg2_videos.py` (checked against `videos.json`); reference tensors are the spike's `.npz` files (outside Git, every array checked against `tensors.json`). Development evidence; the manifests' gate entries are left to the maintainer.

## Staged evaluator

`model-pipeline evaluate model-pipeline/registry/embeddinggemma-2/video-fp32-cpu/manifest.yaml --results <dir> --out <dir> --reference-tensors <ref-clean-tensors> --require-gates G1,G2` (new task `video-embedding`, commit `fac5041`), stage results from `ai-dotnet/tools/Starlings.Fidelity.Tool -- embeddinggemma2-videos` (frames from the adapter, `AllowVideosWithoutTiming` so the metadata-less row is evaluated too), both at `dd1ed7f` with the protected evidence verified against Git: **exit 0, first divergence none, G1 passed, G2 passed** (`report.md`). Stage 1: ids on 36 rows; frame indices, decoded frames, per-frame RGB (FFmpeg major 8), resized frames, pixel values and positions on 32 video inputs; the still image's RGB; all exact. Stage 3: embedding max abs 1.69e-6, min cosine 0.999999999918 (36 rows), soft tokens 5.81e-5 and token embeddings 2.10e-4 row-relative, both batch layouts 0 against single rows, provider options `{}`. CUDA has no evaluator run (the fidelity tool references the CPU natives); the CUDA numbers above come from the test project.

## Release drill

See `release-drill-excerpt.txt`: the adapter packs with exactly `Starlings.Models.EmbeddingGemma2 [0.1.0-preview.4]` and `FFmpeg.AutoGen [8.1.0]` as dependencies and no FFmpeg library inside any package; FFmpeg.AutoGen is restored only for the EmbeddingGemma2Search sample, no Sdcb.FFmpeg or FFmpeg binary package anywhere, and no FFmpeg library in the consumer package cache or any build output. With the user-supplied FFmpeg (`--ffmpeg-dir`) the sample's text-to-video search runs offline from the packages.
