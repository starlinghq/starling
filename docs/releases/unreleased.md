# ai-dotnet: unreleased changes

Changes merged to `main` after the last release record, collected here for the next one. The release-candidate change moves them into `ai-<version>.md` and empties this file. Nothing here is published until then.

## Generated capability records for every model package (#177)

`ModelProfileCapabilities` records, generated from the registry manifests by `model-pipeline catalog` (`ProfileCapabilities.g.cs`, checked by `catalog --check`), now cover every registered profile, not only e5, EmbeddingGemma 2 and GLiNER2. New members: `BertCapabilities.ProfileCapabilities` (the seven BERT-family profiles), `KevCapabilities.ProfileCapabilities` (`Starlings.Models.Kev.Onnx`), `Qwen35Capabilities.ProfileCapabilities` (`Starlings.Models.Qwen35.OnnxGenAI`), the new `QwenChatCapabilities.ProfileCapabilities` (`Starlings.Models.QwenChat.OnnxGenAI`), `Lfm3Capabilities.ProfileCapabilities` and `WhisperCapabilities.ProfileCapabilities`. Each package's contract tests compare every record with its manifest field for field. **Dependency change:** `Starlings.Models.Kev.Onnx`, `Starlings.Models.Qwen35.OnnxGenAI`, `Starlings.Models.QwenChat.OnnxGenAI`, `Starlings.Models.Lfm3` and `Starlings.Models.Whisper` now depend on `Starlings.Models.Abstractions` (which references only `Starlings.Acquisition`). The existing package-wide tables (`All`, `Profiles`) are unchanged. The generation-specific fields of #177 (tool-call mode, structured output, state/prefix reuse, caching style and max output tokens) are not in the record yet.
